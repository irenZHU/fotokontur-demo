# Фотоконтур — прототип лендинга

Статичная страница-прототип главной: первый экран, сцена «Процесс» с живым интерфейсом и подсказками,
блок «Ключевые возможности». Один файл `index.html`, всё встроено, сервер не нужен.

Смотреть: откройте `index.html` или адрес GitHub Pages этого репозитория.
Лучше на экране шириной от 1280 px.
